# Dataset statistics

## Paper-ready description

We use daily mean near-surface air-temperature observations from the European
Climate Assessment & Dataset (ECA&D) as irregular station inputs. The ECA&D
metadata accompanying the download lists 10,507 station records, while the
processed temperature table contains 6,658 station identifiers with valid data
during 2010-2021. The table comprises 27,488,247 station-day observations over
4,383 days. Between 5,828 and 6,574 station observations are available per day
(median 6,296). Because the ECA&D archive extends beyond the reconstruction
domain, 6,500 station identifiers and 26,945,775 station-day observations fall
inside the ERA5 grid bounds (25 W-45 E, 34-72 N); this domain-aligned population
has a median of 6,163 observations per day. All reconstruction methods use the
same ECA&D candidate observations and the same deterministic station subsets for
each date and sparsity condition.

ERA5 2 m temperature (`t2m`) provides the gridded reference analysis. The
downloaded hourly fields were averaged by UTC day and converted from kelvin to
degrees Celsius during model loading. The grid has 153 latitude points and 281
longitude points at 0.25-degree resolution, or 42,993 grid cells per day, over
25 W-45 E and 34-72 N. Although the derived NetCDF includes January 2022, the
experiment uses the 4,383 daily fields from 1 January 2010 through 31 December
2021 to match the ECA&D record. ERA5 is treated as a reference analysis rather
than error-free ground truth.

ERA5 does not have station identifiers. “The same stations” means that ConvCNP,
the transformer, and ordinary kriging receive identical ECA&D station contexts;
their ERA5 targets are sampled from the same gridded reference cells. The final
sparse protocol forms nested context sets of 256, 192, 128, 64, and 26 stations
from the same deterministic station-ID ranking on each day.

The exact machine-readable output is in `dataset_stats.json`, generated by
`dataset_stats.py`.
